# Data

The original datasets used in this project are not included in this repository because of their size and distribution considerations.

The analysis used three aggregated administrative datasets:

- Aadhaar Enrolment
- Aadhaar Demographic Updates
- Aadhaar Biometric Updates

The datasets contain aggregated records by date, state, district, pincode, and age group.

The analysis was performed using the original project datasets in Google Colab and the processed data was used for the Power BI dashboard.

> The data contains aggregated administrative counts and does not contain individual Aadhaar records.
